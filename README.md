Warung Kilat — a fast Indonesian warung cooking game. Customers order nasi dishes (ayam goreng, telur dadar, sayur, sambal, komplit); you grab raw ingredients, fry them in the wok or chop them on the board, assemble the dish on the plate and serve it before patience runs out. Original art drawn in code, no assets, no network.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
